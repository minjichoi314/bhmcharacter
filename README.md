# Festival Pad Gallery v7

## 이번 수정
- 오른쪽 노트 / 줄 / 소감 입력 전체 삭제
- 일러스트 장식 전체 삭제
- `현장 참여 패드` 문구 삭제
- 그리기 화면만 남김
- 주요 색상을 원형 팔레트로 표시
- 전송 버튼의 검은 테두리 삭제
- 포인터 이벤트를 다시 작성해 패드/마우스에서 그리기 안정성 개선
- 디지털 갤러리 칠판 + 포스트잇 + 마스킹테이프 스타일 유지

## 적용
1. `config.js`에 실제 Supabase URL / Publishable key 입력
2. 필요하면 `supabase/schema.sql` 실행
3. GitHub 저장소 파일을 v7 전체로 교체
4. GitHub Pages 재배포
