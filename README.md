# Festival Pad Gallery v3

변경 사항:
- 그림 그리기 화면을 메모지/노트 느낌의 레이아웃으로 변경
- 한 줄 제목 입력 삭제
- 제출 시 title은 내부적으로 `축제 참여 작품`으로 저장
- gallery.html은 밝은 축제 포스터 느낌 배경 적용

- gallery.html
